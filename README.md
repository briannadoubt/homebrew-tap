# Homebrew Tap

Personal Homebrew tap for [@briannadoubt](https://github.com/briannadoubt)'s CLI tools.

## Installation

```bash
brew tap briannadoubt/tap
```

## Available Formulae

### [Compote](https://github.com/briannadoubt/compote)
A docker-compose like tool using Apple's Containerization framework for macOS.

```bash
brew install compote
```

Features:
- Full VM runtime using Apple's Virtualization framework
- Docker Compose compatibility
- Automatic Linux kernel installation
- Service orchestration with dependencies
- Volume and network management

## Adding More Tools

As more tools are released, they'll be added here. Install any tool with:

```bash
brew install <tool-name>
```

## Manual Installation

If you prefer not to tap, you can install directly:

```bash
brew install briannadoubt/tap/<formula-name>
```
